Investment Purchase Tracker — PA2

Crispen Chachengwa · COP 5818

  1. Open a terminal in this project folder. Use Node.js 24.15.0 or later in the 24.x line.
  2. Run npm ci.
  3. Copy .env.example to .env and replace SESSION_SECRET with a new random value of at least 32 characters. README.md provides the command.
  4. Run npm start, then open http://localhost:3000.
  5. Register a fictional account, log in, and add purchases.

Read README.md for explanations and test-report.md for observed results. Reviewed screenshots are included in evidence/. To capture them again, run npx playwright install chromium followed by npm run evidence. This uses a temporary database and writes evidence into the evidence folder.

Run npm test and npm run test:integration to repeat automated checks. Do not submit .env, database files, node_modules or .git.
